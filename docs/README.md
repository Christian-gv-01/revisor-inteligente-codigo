## Anexos técnicos e historial

Los demás documentos numerados, contratos, revisiones de PR y protocolos conservan su procedencia para auditoría. No deben presentarse como versiones actuales solo por aparecer en el repositorio. Los archivos anteriores de presentación y ADR están en [histórico](historico/README.md).

**Diferenciar siempre:** pruebas simuladas ≠ resultados reales del modelo; un ZIP generado ≠ un ZIP subido al portal; citas encontradas ≠ pertinencia garantizada.
